# ProducktivityApp
Producktivity is a productivity web application that allows users to stay motivated towards their short-term and/or long-term goals through a gamified interface.

## Description
 The core idea of our software is to have each user take care of a personal pet through completing their tasks/goals. Points will be rewarded to the user based on the difficulty or longevity of a goal, which in turn, allows them to be used on their pet to maintain their happiness.

## Getting Started
### Dependencies
Node 

### Installing
npm install

#### For backend
    cd producktivity/backend
    py -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install -r requirements.txt

### Executing program
    cd producktivity
    npm run dev
    
#### For backend
    python app.py
